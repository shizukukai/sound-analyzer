# Sound Analyzer - リアルタイム音程チェッカー

歌の練習に最適なリアルタイム音程チェッカーです。マイクから入力した音声の音程を即座に検出し、視覚的にフィードバックします。

## 機能

- 🎤 リアルタイム音程検出
- 🎵 音名表示（日本語/英語）
- 📊 周波数表示（Hz）
- 📈 音程の正確さメーター
- 🌊 波形表示

## 使い方

1. ブラウザで`index.html`を開く
2. 「開始」ボタンをクリック
3. ブラウザからマイク使用許可を求められるので「許可」を選択
4. 歌ったり楽器を演奏したりすると、音程がリアルタイムで表示されます
5. 「停止」ボタンで終了

## 対応ブラウザ

- Chrome (推奨)
- Firefox
- Safari
- Edge

## 技術仕様

- **音程検出アルゴリズム**: 自己相関法とYINアルゴリズムの組み合わせ
- **サンプリングレート**: 44.1kHz
- **検出可能周波数範囲**: 80Hz〜1000Hz
- **レイテンシ**: 100ms以下

## ファイル構成

- `index.html` - メインHTMLファイル
- `styles.css` - スタイルシート
- `app.js` - アプリケーションのメインロジック
- `pitch-detector.js` - 音程検出アルゴリズム
- `requirements.md` - 要件定義書

## ローカルでの実行方法

### 方法1: 直接開く
`index.html`をダブルクリックしてブラウザで開きます。

### 方法2: ローカルサーバーを使用（推奨）
```bash
# Python 3の場合
python -m http.server 8000

# Node.jsの場合（http-serverをインストール済み）
npx http-server

# ブラウザで http://localhost:8000 を開く
```
